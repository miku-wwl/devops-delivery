# 证据目录

每个阶段的原始记录放在 `evidence/<阶段>/`：实验脚本的输出、查询结果、时间线、截图、复盘。教材只引用它们，不复制它们。

## 文件的种类

| 文件 | 含义 |
|---|---|
| `*-prediction.md` | **实验之前**写下并提交的假设（Git 历史中先于对应的运行记录） |
| `*-results.md` | 假设与测量的对照，包括被推翻的假设 |
| `*.log`、`*.txt`、`*.json`、子目录 | 脚本输出的原始记录；有的带分析（`*-analysis.log`） |
| `screens/`、`*.png` | Grafana 截图（未经修改），以及终端记录的渲染图（`manual/tools/term2png.py`，标题栏写明记录时间） |
| `incident-*.md`、`incident/` | 计划外事故的时间线与复盘 |
| `cleanup*.log` | 阶段结束时实验环境的状态 |

## 教材怎样与证据对应

- **证据编号**：出版版正文中的上标数字对应附录 D 的文件清单（每章单独编号），由 `manual/pub/build_pub.py` 从章节源文件中的路径生成。
- **抽查**：`manual/spot-checks.json` 中的每一条把正文里的一句话与证据文件里的一段原文配对，`manual/tools/verify_evidence.py --root v2` 逐条比对（v2.0.0 时 572 条）。
- **图表**：`manual/pub/figures.py` 为每幅实测数据图登记来源文件；时间序列直接从证据文件解析，其余的数字与正文、证据核对（`figures.py --check`）。
- **秘密扫描**：同一个核验工具扫描章节与证据中是否出现令牌、密钥的特征。

## 规则

证据在产生之后不修改。记录中的错误（例如一条标注错误的日志行）用追加的说明更正，原文保留；记录不到的东西（Prometheus 只保留几天）要在实验当时写入文件。任何秘密不进入本目录。
