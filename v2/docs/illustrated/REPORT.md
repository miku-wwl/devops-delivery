## 四页样章的实物对照

用户补充本地路径后，已阅读全文并以120 dpi逐页审读《高中物理·加速度》全部4页。参考文件1,116,597字节，SHA-256为 `7734044f418f235d86e5b14592bccf851f3e37c4bfb7817cee3068b7788a0c44`。逐页观察和全书对应关系见 [REFERENCE-REVIEW.md](REFERENCE-REVIEW.md)。

据此补强了三处中间推理：第4章按单位、最忙副本需求、吞吐解释容量模型；第5章用三个副本的算例与容差反例拆开数学目标和控制行动；第10章按预算比例、窗口份额、阈值时间推导告警。其他章节保留已有的情境、机制、反例和迁移练习。样章是教学设计参考，工程事实与实测材料仍来自原固定基线。
