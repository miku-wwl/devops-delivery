# 附录 B　机制术语速查 {#glossary .unnumbered}

<div class="glossary">

**Allocatable**　调度可承诺的资源预算；不同于节点实时空闲量。（1、5）

**Ambiguous outcome**　调用已发出却没收到确定结果；不等于对方未提交。（2、8）

**Ambient**　节点ztunnel负责L4，按需waypoint负责L7的数据面结构。（3）

**APF**　按身份与请求分类、分席位、排队和拒绝；不是独立CPU或内存配额。（11）

**App-of-apps**　根Application创建子Application；配合同步波次表达依赖。（2、9）

**Bulkhead／隔舱**　限制等待某依赖的并发逻辑调用，满时拒绝。（7）

**Burn rate**　窗口错误比例除以错误预算比例；应明确分母与窗口历史。（10）

**Circuit breaker**　依据失败记录在关闭、打开、半开之间转移的保护状态机。（7）

**Compaction**　清除etcd旧修订、使内部页可复用；不等于缩小文件。（11）

**Coordinated omission**　封闭负载因系统变慢而少发请求，遗漏真实需求中的等待。（4）

**CPU quota**　周期内可用CPU时间上限，突发耗尽时可能被暂停。（5）

**Deadline**　整笔请求允许的截止时刻；不同于一次网络尝试的timeout。（7）

**Defragmentation**　重写有效数据库页以回收文件空间；有服务影响。（11）

**DORA**　交付速度与稳定性的事件度量；本项目脚本口径需结合覆盖范围读取。（9）

**Drift／漂移**　现实与声明不同；只有运行比较或持续控制器才会发现。（12）

**Exemplar**　聚合指标中关联具体Trace的样本，不等于全部请求明细。（10）

**Fencing／隔离**　确保旧主库不能继续写入，降低双主与时间线分叉风险。（8）

**FlowSchema**　APF分类规则，匹配请求身份、资源与动词。（11）

**GitOps**　Git保存期望，控制器持续收敛受管理对象；未跟踪对象需另查。（9、13）

**HBONE**　mTLS上的HTTP/2 CONNECT隧道；应用连接被封装。（3）

**HPA**　周期读取指标并改变副本目标的控制器，存在测量与执行延迟。（5）

**Idempotency key**　同一业务操作的稳定身份，用于识别重试与重放。（2）

**Informer**　先取对象快照，再以WATCH维护客户端缓存。（11）

**KEDA**　把事件源指标交给它管理的HPA；积压与到达率用途不同。（5）

**KWOK**　真实控制面与虚拟节点/Pod状态，不运行真实业务容器。（11）

**Little's Law**　稳定且边界一致时，平均在途量=吞吐×平均停留时间。（4）

**MVCC**　多版本并发控制，旧版本形成可读取历史并占用空间。（11）

**Outbox**　事件与业务数据同事务写入，中继稍后发布，缩小双写原子边界。（2）

**PDB**　约束部分自愿中断的预算，不防全部非自愿故障。（5、7）

**PITR**　基础备份与连续WAL重放至目标点；需要完整恢复链。（8）

**PriorityClass**　调度抢占与驱逐排序中的优先级；不直接给更多CPU。（5）

**Requests / Limits**　承诺与竞争依据／强制资源边界，语义不同。（1、5）

**Retry budget**　每次调用存入、重试取出的令牌预算，包含初始突发。（7）

**RPO / RTO**　可接受丢失窗口／恢复时间目标；实测值须声明判据。（8）

**Saga**　多个本地事务与补偿，不提供跨服务统一回滚和隔离。（2）

**Sampling**　头部在开始决策，尾部在收集后决策；后者不能恢复前者丢的数据。（10）

**Server-side apply**　由API合并字段并记录所有权，跨管理者修改可能冲突。（12）

**SLI / SLO**　服务测量定义与目标；错误预算是允许的坏事件量。（10）

**State lock**　阻止并发状态读改写竞争，依赖后端原子语义。（12）

**Sync impersonation**　GitOps以目标项目账号写入，由Kubernetes授权补充边界。（9）

**Sync wave**　同步依赖顺序；健康等待可能形成跨波次循环。（2、9）

**WAL**　描述数据库变化的持久日志，服务于崩溃恢复、复制与归档。（8）

**Watch cache**　API中的资源缓存；减少etcd读但保留编码传输代价。（11）

**Waypoint / ztunnel**　Ambient的请求层代理／节点级安全隧道代理。（3）

</div>
