# 前言 {#preface .unnumbered}

## 这是一本什么样的书 {-}

这是一本关于现代软件交付与可观测性的实战手册，覆盖持续集成（GitHub Actions、GitLab CI）、Kubernetes 与 Helm、GitOps（Argo CD）、软件供应链安全（Trivy、SBOM、Sigstore、SLSA、Kyverno）、渐进式交付（Argo Rollouts）、可观测性（OpenTelemetry、Prometheus、Tempo、Loki、Grafana，以及 Datadog）、合成测试门禁、SLO 与事故复盘，最后是配置管理（Ansible）。

它与一般教程最大的不同是：**书中的每一条命令都在一台真实的机器上执行过，每一段输出、每一张截图都来自那次执行。**执行中遇到的失败没有被删掉，而是连同排查过程一起写了进来：脚本被 SIGPIPE 悄悄终止、令牌经 ANSI 颜色码泄露进日志、金丝雀因为长连接收不到流量而误杀好版本、被中止的金丝雀把坏配置留给了稳定版、只读根文件系统暴露出 Tempo 的隐藏写入路径……这些“意外”往往比顺利的演示更能说明一项技术是怎么工作的。

## 写给谁 {-}

适合想系统掌握软件交付工程的开发者、运维与 SRE 工程师，以及平台工程方向的学习者。你需要会使用命令行和 Git 的基本操作，能读懂 YAML，了解 HTTP；能读 Python 和 Bash 更好。**不要求** Kubernetes 经验：第 5 章从“期望状态与调和”讲起，只讲本书用得到的部分。

## 这本书是怎样写成的 {-}

全部实验由 AI 编码助手 Claude Code 在作者的电脑上（Windows 11 + WSL2）逐阶段执行，作者给出目标、审阅并决定需要人来决定的事情。为了让“每一步都真实执行过”这句话可以被检查，全书遵守以下规则：

- **证据可追溯。** 终端输出来自 `automation/evidence/transcript.sh` 录制的记录（`evidence/` 目录），图注中标明“终端记录渲染”或“页面截图”；每章的实验记录在 `docs/experiments/` 中。附录 E 说明了证据的组织方式和核验方法。
- **状态如实。** 每个阶段的状态只取 `VALIDATED`（已验证）、`PARTIAL`（部分验证）、`NOT_RUN`（未执行）、`BLOCKED`（缺少外部条件）之一，没做的事不写成做过。例如官方 GitHub Skills 练习需要新建公开仓库，Datadog 实验的网页部分需要本人登录，这些都标为未完成。
- **错了就改，并留下记录。** 后面的章节发现前面的结论有误时，原处加上勘误，而不是悄悄改掉。第 8 章的勘误和第 12 章的事故复盘就是这样来的。
- **该由人决定的事留给人。** 合并到 main 的 PR、生产发布的审批、Datadog 的登录与问卷、认证考试，都由作者本人完成。
- **引用有出处。** 原理部分参考了各项目的官方文档、OpenGitOps 原则、Google SRE Workbook 等公开资料；Datadog Learning Center 的课程内容只做概括和对照，不转载原文。

## 怎样阅读 {-}

每章的结构基本相同：

1. **导语与本章目标**：要解决什么问题，产出什么，验收标准是什么，学完应当会什么；
2. **原理**：先讲清楚“为什么”和“是怎么工作的”，带有架构图；
3. **分步实验**：完整的命令、关键代码的逐段解释、真实的输出与截图，以及过程中真实遇到的问题；
4. **常见问题**：按“症状 → 原因 → 处理”整理；
5. **练习**：理解、动手、排障、设计几类题目，参考答案在附录 B；
6. **小结**。

第 1 章给出全书的全景、知识地图和几条学习路径。按顺序从第 2 章读到第 13 章是最完整的路线；时间有限时，可以按第 1 章的建议只走其中一条路径。

## 排版约定 {-}

| 形式 | 含义 |
|---|---|
| 深色背景的代码块 | 终端记录。以 `$ ` 开头的行是命令（绿色），其余是原样输出；`[exit N]`（红色）表示这条命令以非零状态退出，是真实发生的失败；`# ` 开头的是注释；`PS>` 开头的命令在 Windows PowerShell 中执行 |
| 浅色背景的代码块 | 源代码、配置文件、命令示例 |
| “原理”“说明”“提示”“注意”“警告”“练习”方框 | 分别为原理解释、补充说明、实用技巧、容易出错的地方、可能造成损失的操作、课后练习 |
| `evidence/pN/...`、`sha256:4bb4aac3…` | 仓库中的证据文件（路径相对于仓库根目录）；digest 和提交号通常只写前几位，完整值见证据 |
| 时间 | 证据中的时间一般为 UTC；部分浏览器截图显示 Windows 本地时区（NZDT，UTC+13） |

## 环境与成本 {-}

实验机器为 AMD Ryzen 7 8845HS（16 线程）、31 GB 内存的笔记本电脑，WSL2 发行版最多可用 15 GiB 内存。全部组件同时运行时约使用 8.6 GiB 内存；Docker 镜像约 21 GB，数据卷约 17 GB（2026-11-07 实测）。

所有实验都在本机和 GitHub 的免费额度内完成，没有创建任何云资源；Datadog 部分只使用 Learning Center 免费提供的实验环境。工具版本全部固定（见附录 A）。以后复现时，新版本可能改变行为，书中如实记录的弃用提示（例如 `actions/attest-sbom`、Kyverno 的 `ClusterPolicy`）可以作为迁移的线索。
